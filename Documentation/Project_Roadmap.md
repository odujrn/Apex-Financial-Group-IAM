# Apex Financial Group - IAM Transformation Roadmap

## 📋 Project Purpose

This project is a hands-on learning initiative designed to help me develop practical Identity and Access Management (IAM) skills through the implementation of a simulated enterprise environment.

The project follows the journey of a fictional company, **Apex Financial Group**, as it improves its identity and access management practices using:
- Active Directory
- Microsoft Entra ID
- Role-Based Access Control (RBAC)
- Multi-Factor Authentication (MFA)
- Single Sign-On (SSO)
- Identity Governance concepts

---

## 🎯 Success Criteria

By the end of the project, I should be able to:

- Explain Active Directory fundamentals
- Demonstrate RBAC implementation
- Configure a hybrid identity environment
- Implement MFA and Conditional Access
- Configure Single Sign-On
- Automate user management tasks
- Discuss identity governance concepts
- Present the project confidently during technical interviews

## 🗓️ Project Phases

---

### Phase 1: Build the Identity Foundation

**Goals:**
- Install Windows Server 2022
- Create a Domain Controller (DC01)
- Configure Active Directory
- Create Organizational Units (OUs)
- Create users and security groups
- Join a Windows 11 workstation to the domain

**What I Will Learn:**
- Active Directory basics
- User and group management
- Domain administration
- Organizational Unit design

**Deliverables:**
- Domain Controller
- Active Directory structure
- User accounts
- Security groups
- Screenshots and documentation
