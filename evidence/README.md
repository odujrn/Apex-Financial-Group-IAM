# Evidence Guide

Evidence is organized by implementation phase. A screenshot should prove one important configuration or test result and use a descriptive numbered filename.

Before publishing, redact:

- Passwords and recovery information
- License keys and tokens
- Personal email addresses
- Unrelated accounts or systems
- Public IP addresses when unnecessary

Evidence supports the written analysis; it does not replace it. Each completed phase README should link to its relevant files and explain what each result demonstrates.
