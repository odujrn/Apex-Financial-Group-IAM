# Phase 6 — Governance and Audit

**Status:** Planned

**Estimated effort:** 3–4 hours

## Objective

Turn the technical implementation into a repeatable IAM control process with review evidence.

## Planned deliverables

- Role and entitlement catalog
- Quarterly access-review worksheet
- Joiner, mover, and leaver procedure
- Privileged-group review
- Change record using the repository template
- Risk register with owner, likelihood, impact, treatment, and status
- Final findings and remediation report

## Sample review questions

- Does each identity have a current business owner?
- Does each group have a documented purpose?
- Are any permissions assigned directly to users?
- Do terminated or disabled users retain group membership?
- Are privileged roles separated from ordinary work?
- Do evidence and implementation match the stated control?

## Completion criteria

The final audit pack must distinguish implemented controls, accepted limitations, open risks, and future improvements. It must not claim regulatory compliance without an authorized formal assessment.
