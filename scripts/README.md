# Scripts

This directory is reserved for scripts that have been executed and validated in the lab.

Planned Phase 3 scripts include:

- `New-ApexUser.ps1`
- `Move-ApexUser.ps1`
- `Disable-ApexUser.ps1`

Do not publish scripts containing passwords, access tokens, tenant secrets, real personal data, or untested destructive logic. Each script should include help text, parameter validation, error handling, and a short test record in its phase documentation.
